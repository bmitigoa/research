# AI-Based Rental Housing Prediction and Visualization System

This repository contains my MSc research project titled:

## “A Machine Learning-based Mobile Application with Augmented Reality for Rental Housing Prediction and Visualisation in Nairobi”

The research focuses on combining Machine Learning (ML) and Augmented Reality (AR) to improve rental housing decision-making in Nairobi through:

- Rental price prediction
- Property visualization using AR
- Mobile application integration
- Data-driven housing analytics

## Research Areas

- Artificial Intelligence
- Machine Learning
- Data Analytics
- Augmented Reality
- Mobile Application Development
- Predictive Analytics

## Key Technologies

- Python
- LightGBM
- TensorFlow
- Firebase
- Android (Kotlin)
- ARCore
